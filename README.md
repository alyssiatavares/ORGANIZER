# ORGANIZER – Automatically organize your files

This is a Python application that automatically organizes the files in a selected folder by sorting them into categories (documents, images, videos, music, etc.). It’s perfect for anyone who has a messy desktop (or any folder) and wants to tidy it up with **just one click**!

---

## Technologies Used

- Python 3.12
- `os` (for file and directory handling)

---

## How It Works

1. The app opens a window for you to choose a folder.
2. It scans all files in that folder.
3. Based on the file extension, it moves each file into a categorized subfolder:
   - `Documents`: `.pdf`, `.docx`, `.pptx`, etc.
   - `Images`: `.jpg`, `.png`, `.gif`, etc.
   - `Videos`: `.mp4`, `.avi`, etc.
   - `Music`: `.mp3`, `.wav`, etc.
   - `Archives`: `.zip`, `.rar`, etc.
   - `Others`: any file that doesn’t match the categories above
